# 📝 Formulário Web

Projeto desenvolvido para praticar os fundamentos do desenvolvimento web, utilizando HTML e CSS.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 🎯 Objetivo

Desenvolver uma página de formulário e praticar a criação e a estilização de elementos HTML.

## 📚 Aprendizados

- Estruturação de páginas com HTML.
- Estilização de elementos com CSS.
- Organização de arquivos de um projeto web.

## ▶️ Como executar

1. Abra a pasta do projeto.
2. Entre na pasta `formulario`.
3. Localize o arquivo HTML principal.
4. Abra-o no navegador.
